# How to Use This Agent

## Purpose

Use this agent to find Franchise Integration guidance, troubleshoot known issues, review mapping examples, and create validation checklists.

## Best Use Cases

- Find implementation patterns.
- Troubleshoot known integration issues.
- Review mapping examples.
- Find similar resolved cases.
- Prepare validation checklists.
- Understand escalation criteria.
- Help onboard new consultants.

## Best Prompt Format

Include the following details:

- Customer or context
- Integration type
- Environment
- Issue or goal
- Error message or symptom
- What you already checked
- Expected outcome
