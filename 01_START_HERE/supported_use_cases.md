# Supported Use Cases

## Supported

This agent supports:

- Franchise Integration implementation guidance
- Offer file setup
- FADV API troubleshooting
- API timeout troubleshooting
- Mapping value guidance
- Candidate journey mapping guidance
- Validation checklist creation
- Similar case lookup
- Escalation summary creation
- Case documentation support

## Not Supported

This agent does not support:

- Handling secrets or credentials
- Making production changes
- Bypassing approval processes
- Providing undocumented workarounds
- Replacing human review for high-risk production changes
- Providing guidance outside approved integration knowledge
