# Escalation Matrix

## Purpose

Define when and where to escalate integration cases.

## Escalation Triggers

| Scenario | Escalate To | Reason |
|---|---|---|
| Production issue | Integration lead / support lead | Production impact |
| Security or credentials | Security / platform owner | Sensitive access |
| Undocumented integration behavior | Senior consultant | Requires expert review |
| Customer-specific exception | Customer Success + integration lead | Requires approval |
| Data loss or duplicate data risk | Engineering / integration lead | High business impact |
| Candidate status issue | Product/integration owner | Downstream workflow impact |

## Required Escalation Information

- Customer
- Integration type
- Environment
- Issue summary
- Error message
- Impact
- What has been checked
- Recommended next step
