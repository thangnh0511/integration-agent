# Glossary: Integration Terms

## API

A method for systems to communicate programmatically.

## Payload

The data sent in an API request or response.

## Mapping

The process of connecting fields or values from one system to another.

## Timeout

The maximum time a system waits for a response before failing the request.

## Endpoint

A specific API URL or route used to perform an action.

## Offer File

A file containing offer-related data exchanged between systems.

## Environment

A system instance such as test, staging, or production.

## Retry

A repeated attempt to perform an API call or process after a failure.

## Downstream System

A system that receives data from another system.

## Validation

The process of confirming that a change behaves as expected.
