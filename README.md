# Franchise Integration Knowledge Base

## Purpose

This folder contains the knowledge base, rules, skills, workflows, case studies, troubleshooting guides, mapping examples, templates, escalation guidance, and glossary for the Sana Franchise Integration Knowledge Assistant.

## Recommended Sana Agent Setup

Connect this folder as the primary knowledge source for the Sana Agent.

Do not connect:

- 98_DRAFT_NOT_CONNECTED
- 99_ARCHIVE
