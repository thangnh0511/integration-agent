# Common Integration Patterns

## API Integration

Use when systems exchange data through API calls.

Common concerns:

- Authentication
- Timeout
- Retry behavior
- Payload validation
- Rate limits
- Error handling

## File-Based Integration

Use when systems exchange data through files.

Common concerns:

- File format
- Required fields
- File delivery method
- File frequency
- Validation
- Error handling

## Mapping-Based Configuration

Use when values from one system must be mapped to values in another system.

Common concerns:

- Source field
- Target field
- Journey or workflow
- Environment
- Downstream impact
- Customer-specific exceptions
