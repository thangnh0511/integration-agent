# Franchise Integration Overview

## Overview

Franchise integrations require careful handling because different franchise groups may have different workflows, mappings, or customer-specific requirements.

## When to Use

Use this guide when the request involves:

- Franchise-specific setup
- Franchise customer data flow
- Offer file integration for franchise workflows
- Journey-specific mapping
- Customer-specific routing or configuration

## Required Context

Collect:

- Customer or franchise group
- Integration type
- Environment
- Source system
- Target system
- Required data fields
- Journey or workflow
- Current behavior
- Expected behavior
- Production impact

## Standard Approach

1. Confirm the franchise integration pattern.
2. Review customer-specific notes if available.
3. Confirm required fields and mapping rules.
4. Validate the workflow in non-production.
5. Confirm downstream behavior.
6. Document the final setup.
7. Escalate if the requirement conflicts with standard patterns.

## Common Risks

- Customer-specific mapping conflicts
- Incomplete data fields
- Incorrect routing
- Incorrect journey assignment
- Production candidate impact
